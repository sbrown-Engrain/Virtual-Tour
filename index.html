Virtual Tour Match

Load your unit list once, drop in tour links, and export a CSV that matches the upload template exactly — no more hunting for the right row in a spreadsheet.

How to use this — 5 steps
  1. Load your unit list. Drop a file in or use Browse files… and it loads right away — no extra click needed. Only use Load pasted text below it if you're pasting CSV text in by hand instead of uploading a file.
  2. Add client-provided links (optional). If a client sent you a separate file with unit numbers or floor plan names and tour links, drop it in the amber box below. Check that the identifier column, its type (unit number vs. floor plan), and the URL column all look right, then click Match & fill from file. A floor plan match fills in every unit that shares that plan.
  3. Add virtual tour links by typing. In the Paste-match a list of links box, type the unit number, a comma, then the tour URL — one per line.
    Example: 1101,https://my.matterport.com/show/?m=2S4tXzptYuy
    Click Match & fill and every line gets matched to its unit automatically. A floor plan name works the same way and fills in every unit on that plan. If the same unit number shows up more than once with different floor plans, use unit number | floor plan instead (e.g. 1101 | A1,https://…) so it only fills in that one exact unit.
  4. Fill in what's left. Click the Missing filter to see only unlinked units. Click into a Tour URL box, paste the link, and press Enter — it jumps straight to the next empty one so you never have to reach for the mouse.
  5. Export. Click Export CSV. It'll try to download automatically; if it doesn't, use the Download or Copy to clipboard options in the popup instead.

Tip: the progress bar above step 4 always shows how many units still need a link.

2Paste-match a list of links

Paste rows in the form key, url (or tab-separated) — one per line, any order. The key can be a unit_number (matches one unit), a plain floor plan name/ID like A1, or the full copied floor-plan text like {"name":"2 Bedroom, 2 Bathroom",...} — commas inside it won't confuse the match. A floor plan match fills in every unit on that plan.

If the same unit number is used more than once with different floor plans, use unit_number | floor plan (unit number, a pipe |, then the floor plan) as the key so it only fills in that exact unit. Example: 101 | A1, https://my.matterport.com/show/?m=abc123
